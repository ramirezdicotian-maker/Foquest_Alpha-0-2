# FoQuest — Alpha 0.2

Juego web de un solo archivo (`index.html`), sin dependencias ni instalación.

## Jugar en línea

https://ramirezdicotian-maker.github.io/Foquest_Alpha-0-2/

## Jugar en tu computador

1. Descarga o clona el repositorio:
   ```bash
   git clone https://github.com/ramirezdicotian-maker/Foquest_Alpha-0-2.git
   ```
2. Abre `index.html` con doble clic en tu navegador (Chrome, Edge o Firefox).

Opcional, con un servidor local:
```bash
cd Foquest_Alpha-0-2
python3 -m http.server 8000
# luego abre http://localhost:8000
```
